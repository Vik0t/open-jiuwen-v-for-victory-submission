# Отдельный кандидат v5: формат JSON для ремонта кода

Техническая проверка пройдена. Это отдельный источник, root не изменён:
`experiments/agent_night_2026-11-09/candidate_v5_json_source`.

База — точная frozen-копия selected_v4_source. Из прежнего
common_v2_batch_json_source дословно перенесены только три замены в двух файлах:
необязательный json_mode=False в Gateway.answer, response_format=json_object
через ModelRequestConfig.extra_body при включённом флаге и передача True только
для coding из компактного цикла.

Остальные десять файлов совпадают побайтно. Промпты, SymPy-подсказка, пределы,
порядок задач, parser и логика бюджета сохранены. Обратное удаление трёх замен
восстанавливает оба файла v4 побайтно; snippets совпадают с прежним механизмом.

В строгом offline Docker повторены прежние семь actual-SDK MockTransport
проверок для v4 и v5: четыре типа задачи, вызов Gateway с флагом по умолчанию,
неизвестный расход и выход за предел output. Все 14 случаев пройдены. Полные
HTTP-объекты math/data_analysis/search и прямого default-вызова совпали с v4.
В coding единственная разница payload — response_format типа json_object.
Расход по известной квитанции прежний; при неизвестном расходе резерв остаётся
удержанным и следующий HTTP-вызов не уходит. При превышении output бюджет
замораживается и второй запрос тоже не отправляется. Резерв JSON-вызова
учитывает увеличившийся сериализованный HTTP payload.

Все 12 хешей кандидата, базы и root повторно проверены после испытания. Новые
64/16 условия и результаты не читались. API и настоящих генераций — 0; ни одна
программа из ответа модели не исполнялась: ответы MockTransport фиксированы.
Первый сборщик отчёта остановился на SDK INFO перед JSON; SDK-сценарий v4 уже
успел пройти, поэтому его сохранённый результат разобран без повторного запуска.

Manifest и diff лежат рядом; точные команды и JSON результата —
`candidate_v5_json_validation/validation.json`. Это техническая совместимость,
а не подтверждение поддержки формата конкурсным провайдером или роста качества.
Выбор и независимая оценка остаются у root.
