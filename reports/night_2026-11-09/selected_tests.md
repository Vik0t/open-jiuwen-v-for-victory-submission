# Проверки выбранного кода

Сначала проверен набор 12 файлов v4 из selection.json. Итоговая v5 с JSON
имеет отдельную фиксацию delivery_selection.json; её текущие файлы повторно
прошли 126 локальных случаев,25 пропусков и 23 subtests: delivered_runtime_pytest.txt.
Каждый зафиксированный источник сравнения сохраняется без изменений.

`pytest tests/test_contest*.py` в обычном окружении проекта: **126 passed,
25 skipped, 23 subtests passed**. Пропуски относятся к отдельному SDK-окружению
и Linux-контейнеру; они не объявлены успешными испытаниями Mac.

Настоящий SDK отдельно проверен семью тестами `test_contest_gateway.py`:
**7/7**, искусственные HTTP-ответы, генераций модели **0**. Проверены отдельные
квитанции параллельных запросов, фактическая сумма, отказ до отправки,
неизвестный расход, отмена и отсутствие повторов.

Первый прогон выявил устаревшие ожидания трёх тестов: они предполагали пять
одновременных обращений по умолчанию. Текущий сервис допускает три; этот предел
уже вошёл в ранее проверенные снимки кода. Тест общей конкурентной выдачи
бюджета теперь явно задаёт допустимый конфигурируемый предел пять, а отдельные
случаи проверяют default=3 и явный=5. Резерв входа в этом тесте приведён
в соответствие с его фактическим usage. Добавлены два случая: превышение
только входной либо только выходной границы блокирует следующие запросы,
даже если общая цена не превышает сумму резерва. Runtime ради тестов не менялся.

Выводы сохранены в selected_runtime_pytest.txt и selected_gateway_unittest.txt.
Отдельно настоящий openJiuwen Workflow прошёл **6/6** локальных сценариев
без модели; вывод — selected_workflow_unittest.txt.
Это технические проверки, не число правильных решений Qwen и не официальный
результат соревнования. Обе архитектуры образа и точный архив проверяются
отдельно; их результаты не следует выводить из этих чисел.

JSON-кандидат отдельно прошёл семь примеров настоящего SDK на каждой из
двух версий (14 проверок), включая coding response_format и прежние некодовые
запросы. Исходный код v5 в корне совпадает с этим проверенным снимком.
