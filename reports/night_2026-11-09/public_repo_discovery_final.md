## Сравнение с нашей реализацией

Общая идея похожа: дешёвые локальные обработчики, оценка цены и ценности задачи, обращение к модели для остального. Отличаются конкретные механизмы. В уже проверенных нами снимках `common_v2` есть целочисленный учёт, резерв перед отправкой и остановка при неизвестном расходе; публичная проверка кода обнаруживает тесты и требует ненулевого их числа. Наш код передаёт README отдельно и допускает несколько точных правок одного файла вместо обязательной полной перезаписи.

Из этого **не следует**, что наш агент получил бы больше баллов: чужая версия не запускалась на одинаковых входах и бюджете. На следующий цикл исследования полезна сама граница вопросов: реально ли оценщик использует обученные веса; оценивается ли выполнимость задачи или вероятность её решения данным агентом; какая информация входит в запрос; что именно удостоверяет успешный тест. Ночных изменений кода по этой находке не делалось.

## Как искали и что могли пропустить

Восемь анонимных запросов включали `openJiuwen Challenge 2026`, `neuraldeep agent budget`, точное `BudgetAwareTokenEstimation`, адрес соревнования и сочетание openJiuwen/hackathon. У каждого был фильтр `is:public`. Широкий запрос дал 139 репозиториев: получены обе страницы; отдельно проверены публичные fork. Другие соревнования CareerSim/CCF BDCI и Hack the North, а также общие клиенты NeuralDeep не записывались как участники этого конкурса.

Запросы, полные URL, ответы и ограничения: [поиск](public_repo_discovery_final_search.json), [дополнительная страница и fork](public_repo_discovery_final_search_extra.json), [итоговый JSON](public_repo_discovery_final.json). Точный символ не встретился в поиске по имени/описанию/README. Поиск по всему коду не завершён: анонимный endpoint вернул HTTP 403. Это не доказательство отсутствия символа в публичном коде.

Общий API метаданных GitHub также упёрся в лимит; для снимка использованы анонимные HTML/raw/Atom с закреплённым SHA. Не читались закрытые репозитории, профили аккаунтов, ключи или условия наших отложенных наборов. Поиск не охватывает ещё не проиндексированные, переименованные, будущие и закрытые проекты. Официальных мест и результатов этот отчёт не устанавливает.
