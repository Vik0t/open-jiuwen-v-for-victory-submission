# Причины ошибок: разбор сохранённого сравнения от 8 ноября

Разобраны существующие результаты `experiments/fresh_noreason_2026-11-08`:
`primary_h1` — прежний гибридный агент, `primary_r1` — обычный ReAct на том же
Qwen3.8-27B. Новых обращений к модели в этом разборе нет. Эти задачи уже раскрыты
разработке; дальнейший прогресс нужно подтверждать на отдельном новом наборе.

Фактически сохранённые результаты: гибрид — 4 из 10 решаемых задач, обычный
агент — 3 из 10. Это одна пара запусков, а исходный обычный агент содержит
подтверждённую ошибку сдачи. Делать вывод о превосходстве гибрида нельзя.

## Главные подтверждённые причины

1. **Правильное решение теряется при сдаче.** Обычный агент исправил gitignore
   и shortuuid, выполнил доступные тесты успешно, затем вызвал
   `write_file("answer.txt", ...)`. Инструмент запрещает этот путь. Отметка
   `DONE` не сохранилась. Временные копии этих решений с добавленной отметкой
   прошли соответственно 15/15 и 20/20 расширенных проверок. Исходные файлы и
   оценки не менялись; это проверка причины, не новые заработанные баллы.

2. **Успех на одном тесте объявляется полным решением.** Гибридный перебор
   синтаксических мутаций заменил `pattern[0] == '/'` на `pattern[0] != '/'`
   в gitignore. Теперь первая буква удаляется почти у каждого шаблона. Один
   открытый пример случайно исправляется, но расширенная проверка даёт четыре
   проваленных проверки и одну ошибку выполнения из пятнадцати. Локальный метод
   сохранил `DONE` и не передал задачу модели. Это подтверждённая подгонка под
   слабый открытый тест, а не надёжное исправление.

3. **Числовые задачи решаются текстовой генерацией без вычисления.** Гибрид
   записал 10244 вместо 15042 для объединения таблиц и 63 вместо 48 для выбора
   ресурсов. Обычный агент получил правильные значения выполнением Python.
   Здесь нужен инструмент вычисления и проверка ограничений, а не усложнение
   прогноза расходов.

4. **Фиксированный запас на ответ оставляет задачи без попытки.** Обычный агент
   всегда запрашивал до 2048 выходных токенов. При остатке 2176.2 единицы
   бюджета следующий запрос вместе с консервативной оценкой входа уже не
   помещался. В журнале пять отказов до отправки запроса; latest_event,
   pmtiles и missing_denominator не получили ни одного обращения к модели.
   Отсутствие ответа на последней задаче не доказывает распознавание её
   нерешаемости.

5. **Журнал не позволяет восстановить часть причин.** Для ряда успешных HTTP
   ответов стоит `saved=false`, но сам окончательный текст не записан.
   Нельзя отличить неверный формат, неверное число, лишнее объяснение или
   отказ проверки кода. В чистой паре нет `finish_reason=length`, поэтому
   приписывать эти потери обрезанию генерации нельзя.

## Что проверять после изменения архитектуры

- Отдельный `submit_answer` сохраняет результат сразу; успешная сдача не
  требует ещё одного обращения к модели. Для кода он проверяет доступные тесты
  и пишет `DONE` рядом с описанием задачи. Запись файла через общий редактор
  для этого не используется.
- Неверный ответ возвращает понятную причину: много строк, неверный тип,
  пустое значение, синтаксическая ошибка или провал тестов. В журнале остаются
  фактический окончательный текст и причина отказа. Успешный HTTP не считается
  успешной сдачей.
- На задаче с одним слабым тестом нельзя принимать произвольную синтаксическую
  мутацию за гарантированное исправление. Такой результат — только кандидат.
  Нужны проверки обычного поведения, граничных случаев и контрпримеров,
  сформулированные по условию и исходному коду, без просмотра скрытых тестов.
- Для таблиц и числовых ограничений агент получает выполнение короткого Python
  в изолированной среде. Результат инструмента и итоговый ответ сопоставляются.
- При малом остатке бюджета предел ответа уменьшается. Неотправленный запрос
  записывается отдельно от сетевой ошибки и ошибки рассуждения.
- Проверки редактирования должны покрывать неоднозначное совпадение, сохранение
  UTF-8 и переводов строк, атомарность ошибки, запрет изменения тестов,
  метаданных и выхода из рабочего каталога.

## Где лежат доказательства

- `experiments/fresh_noreason_2026-11-08/baseline.py`: запрет `answer.txt` в
  редакторе и предел 2048 токенов в обычном агенте.
- `experiments/fresh_noreason_2026-11-08/runs/primary_r1/tools.json`:
  последовательность исправления, успешных тестов и отклонённой записи ответа.
- `experiments/fresh_noreason_2026-11-08/runs/primary_h1/task_results.json`:
  ложное `solved` локального исправления и результаты сохранения ответов модели.
- `runs/primary_h1/score.json`, `runs/primary_r1/score.json` внутри того же
  эксперимента: неизменённые исходные оценки.
- `submission_bug_diagnostic.json` рядом с этим отчётом: только
  контрфактическая проверка двух временных копий; хеши исходных результатов
  проверены до и после. Обращений к модели — ноль.
