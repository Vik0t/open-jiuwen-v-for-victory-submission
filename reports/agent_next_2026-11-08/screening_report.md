# Проверка режима JSON на знакомых сорока задачах

**Режим исправил формат ответов, но не достиг заранее заданного порога
пользы. Остаётся экспериментом; в основную версию не переносится.**

Одна парная проверка на уже изученном наборе разработки. Сравнивались
`v3_screen40_io180:r1` и `json_screen40_io180:r1`. Обеим версиям даны одинаковые
задачи, порядок, бюджет 40 000, Qwen3.8-27B без рассуждений, время ожидания
180 секунд и изолированное выполнение Python. Совпадение условий проверено
по двум заморозкам. Отличие кандидата — `response_format=json_object`
для сообщений с действиями. Исторические результаты не подменялись.

| Показатель | Обычный режим | Режим JSON |
|---|---:|---:|
| Баллы / достижимый максимум | 144 / 181 | 146 / 181 |
| Решённых задач / решаемых | 26 / 32 | 27 / 32 |
| Обоснованных отказов при недостатке данных | 8 / 8 | 8 / 8 |
| Фактический расход, выход + вход/10 | 19 644,9 | 19 334,3 |
| HTTP-запросов, все с ответом 200 | 63 | 65 |
| Входных токенов | 95 869 | 98 503 |
| Выходных токенов | 10 058 | 9 484 |
| Синтаксически неразбираемый JSON | 1 | 0 |
| Валидный JSON, но список вместо одного действия | 3 | 0 |
| Всего недопустимых действий | 4 | 0 |
| Ответов с `finish_reason=length` | 0 | 0 |
| Неизвестный расход / удержанный резерв | 0 / 0 | 0 / 0 |

Все четыре недопустимых ответа обычного режима закончились с
`finish_reason=stop`. Их суммарная цена — 2 176,2 единицы. Это не равно
достигнутой экономии: режим изменил также остальные ответы и число шагов.
Один случай — незакрытая JSON-строка с программой, три — массив с единственным
действием вместо самого объекта. В этом запуске ограничение формата устранило
оба вида нарушения. Устойчивость при обрыве по пределу длины здесь не проверена.

| Допустимое действие | Обычный режим | Режим JSON |
|---|---:|---:|
| Выполнить Python | 27 | 32 |
| Правка исходника | 10 | 10 |
| Прочитать файл | 7 | 7 |
| Сохранить ответ | 7 | 8 |
| Отказаться из-за отсутствия данных | 8 | 8 |
| Записать новый исходник | 0 | 0 |

Прибавилась задача `next_002` с наградой 2. Остальные финальные результаты
совпали. У обычного режима в этой задаче не было ошибки JSON; поэтому нельзя
объяснять весь прирост непосредственным исправлением формата одной и той же
программы. Меняются генерация и последовательность действий, а один парный
запуск не отделяет эффект режима от изменчивости модели.

До запуска в [json_screen_protocol.json](json_screen_protocol.json) записано:
новая независимая проверка нужна при **+10 баллах** либо **экономии не менее
10% без потери баллов**. Получено **+2 балла** и **экономия 1,58%**.
Обе ветви порога не выполнены. Дополнительный закрытый набор для этого
кандидата сейчас не расходуем; автоматического переноса в основную версию нет.

В наборе остаются ранее описанные неоднозначности `next_006/007`; обе версии
их не прошли. Их исключение не меняет разницу между версиями и принятое
решение. Это локальный отбор идеи на данных разработки, не независимая
победа над базовым агентом и не официальный результат соревнования.
