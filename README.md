# Агент openJiuwen для задач при общем бюджете

В комплекте — исходники агента, закреплённые зависимости и материалы команды.
Образ Docker собирается из этих исходников; доступы к API и сами задания
передаются отдельно. Полный исследовательский проект с данными, траекториями
и экспериментальными копиями хранится отдельно от этого комплекта.

Начать чтение: [разбор реализации](docs/agent_explained_2026-11-09.md),

Ссылки на experiments, data и .cache относятся к полному проекту.

## Кандидат с точным начальным фрагментом

Для больших Python-файлов агент подставляет тело функции, явно названной в задаче, при единственном совпадении. Исходники и результаты сравнений зафиксированы в CANDIDATE_PROVENANCE.json.

## Редактор больших Python-файлов

Точные замены в существующих файлах поддерживаются до 1 МиБ. Размер файла при правке может вырасти не более чем на 100 000 байт. Результат проходит проверку синтаксиса и записывается атомарно. Данные сравнительных запусков находятся в CANDIDATE_PROVENANCE.json.

## Поиск явно названной функции

Для больших Python-файлов агент может сразу показать точный фрагмент функции с простым именем, если цель явно указана и определение единственное. Данные сравнительных запусков находятся в CANDIDATE_PROVENANCE.json.

## Лицензии в контексте кодовых задач

Три проверенных стандартных текста лицензий остаются доступны в индексе и через `read`. Агент откладывает их чтение, если в публичном контракте нет признаков, что лицензия нужна. Результаты двух сравнений приведены в CANDIDATE_PROVENANCE.json.

## Точная длина границы объединения

Для явно подходящих математических задач в штатном Python доступна функция `rect_union_perimeter`. Она вычисляет длину границы объединения осевых прямоугольников, включая отверстия, в точной рациональной арифметике. Модель указывает координаты из условия. Результаты двух сравнений находятся в CANDIDATE_PROVENANCE.json.

## Передача координат

В подходящих задачах модель может отправить список координат действием `rect_union_answer`. Координаты проходят проверку и поступают в тот же точный вычислитель. Штатный Python-вызов остаётся доступен.

## Сборка и запуск без модели

Используйте рабочую копию заданий: агент сохраняет ответы и исправляет исходники.

```bash
docker build -t jiuwen-contest .
export CONTEST_TASKS_DIR=/absolute/path/to/a-working-copy-of-task-dir
docker run --rm --read-only --network none --cap-drop ALL \
  --security-opt no-new-privileges --cpus=4 --memory=16g --pids-limit=128 \
  --tmpfs /tmp:rw,size=2g,mode=1777 \
  -v "$CONTEST_TASKS_DIR:/tasks:rw" -e TASKS=/tasks -e BUDGET=0 \
  jiuwen-contest --no-llm
```

## Запуск с моделью

Внешний env-файл должен содержать LLM_BASE_URL, LLM_API_KEY, BUDGET и при
необходимости LLM_MODEL. Храните его вне архива. Контейнеру нужен доступ к адресу
LLM_BASE_URL; сеть и шлюз в соревновании задаёт среда запуска.

```bash
export CONTEST_ENV_FILE=/absolute/path/to/private.env
docker run --rm --read-only --cap-drop ALL \
  --security-opt no-new-privileges --cpus=4 --memory=16g --pids-limit=128 \
  --tmpfs /tmp:rw,size=2g,mode=1777 --env-file "$CONTEST_ENV_FILE" \
  -v "$CONTEST_TASKS_DIR:/tasks:rw" -e TASKS=/tasks \
  jiuwen-contest
```

Для обращений к модели BUDGET обязателен; без него бюджет равен нулю.
Конкурсная цена — O + I/10, где O — выходные токены, I — входные.
Это единицы конкурсного бюджета. Ответы появляются рядом с task.json,
общий agent-report.json — в корне заданий.
SHA256_MANIFEST.json содержит SHA-256 и размеры всех файлов комплекта,
кроме самого манифеста и ZIP.
